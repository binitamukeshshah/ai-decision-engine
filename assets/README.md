# Demo assets

This directory contains the reproducible script for recording the project demo.

- [`demo-script.md`](demo-script.md) lists the three live-validated self-hosted selection commands and a short recording checklist.
- `demo.gif` is intentionally absent until a genuine terminal session is recorded.

Do not hand-edit or simulate terminal output. Before publishing a recording, confirm that the terminal contains no credentials, identity data, hostnames, network addresses, or private filesystem paths.
