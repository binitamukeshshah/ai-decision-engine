# Roadmap

v0.1.0 is an early, live-validated routing release. It demonstrates the decision boundary and current integrations; it is not presented as production-ready infrastructure.

## Next

1. Turn the synthetic cases into a repeatable evaluation runner with versioned prompts and runtime metadata.
2. Replace provisional quality and latency values only after repeated measurements and review.
3. Add deployment health checks, operational runbooks, reservation recovery, and a supported service transport.
4. Revalidate OpenClaw catalog and readiness compatibility after every runtime upgrade.

## Later

1. Add separate, end-to-end interfaces and tests before advertising images, embeddings, tools, schema-validated output, or current-information access.
2. Evaluate additional local and cloud models without broadening the approved pool by default.
3. Publish reproducible routing and quality reports with clearly stated hardware, versions, costs, and limitations.
